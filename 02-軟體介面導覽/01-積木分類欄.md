# 2.1 左側積木分類欄

畫面最左邊這一長條，把所有積木依照功能分成好幾類，每個分類前面的顏色小方塊跟展開後積木的顏色是對應的：

![積木分類欄](../images/02-interface/01-toolbox.png)

點一下分類名稱，右邊會展開該類的積木清單（稱為「積木欄」），把想要的積木**用滑鼠拖到畫布上**就可以使用了。再點一次分類名稱、或是點畫布空白處，積木欄會自動收起來。

## 12 個內建分類

| 分類 | 放的是什麼 |
|---|---|
| 控制 | 迴圈、條件判斷（switch/if）、等待 |
| 運算 | 加減乘除、比較、邏輯、亂數 |
| 輸出 | 控制腳位輸出、伺服馬達、蜂鳴器 |
| 輸入 | 讀取腳位、中斷 |
| 通訊 | 序列埠、I2C、SPI |
| 除錯 | 內建 LED 測試 |
| 變數 | 宣告、讀取、設定變數 |
| 陣列 | 一整排的資料 |
| 文字 | 文字變數與操作 |
| 儲存 | 斷電後還記得的記憶體（EEPROM） |
| 副程式 | 把一段積木包成可以重複呼叫的功能 |
| C 語言 | 給進階使用者直接寫 C 程式碼的逃生門 |

詳細每一顆積木怎麼用，看 [積木字典](../04-積木字典/README.md)。

## 最下面兩個特別分類

- **創建積木**（紫色）：自己做新積木的入口，詳見 [自己做積木](../05-自己做積木/README.md)。
- **我的收藏**（黃色）：把常用的一組積木存起來，之後隨時拖出來用，不用重新組一次。

## 小技巧：把積木欄「釘住」

積木欄展開之後，右上角有一個圖釘 📌 圖示，按下去積木欄就會固定展開、不會自動收起來，適合要從同一個分類拖很多顆積木出來的時候用。
