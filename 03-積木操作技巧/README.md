# 三、積木操作技巧

這一章教的不是「有哪些積木」（那是[積木字典](../04-積木字典/README.md)），而是**怎麼更快、更順手地操作積木**——多選、複製、收藏、復原、整理排版這些跟編輯器本身有關的技巧，跟 Scratch、Blockly 系列軟體的基本手感類似。學會這幾招，排一大堆積木會輕鬆很多。
