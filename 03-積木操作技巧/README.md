# 三、積木操作技巧

> 🚧 這一章內容製作中，會陸續補上。以下是已經規劃好的章節，讓你先知道之後會涵蓋哪些內容。

這一章教的是**不管用哪一顆積木都通用**的操作方式——跟 Scratch、Blockly 系列軟體的基本手感類似。

## 規劃中的章節

1. 3.1 拖、接、拔：積木怎麼連在一起
2. 3.2 積木欄圖釘：固定住不要自動收合
3. 3.3 選取積木：單選／Ctrl 加選／Shift 連續選／Shift 拖曳框選
4. 3.4 複製貼上：Ctrl+C／Ctrl+V（貼上後懸浮跟著滑鼠、點一下才放下、Esc 取消）
5. 3.5 Ctrl+拖曳＝直接複製一份
6. 3.6 上一步／下一步（復原、重做）
7. 3.7 Windows 慣用鍵：全選、剪下、刪除
8. 3.8 整理積木（右鍵選單，排列整齊）
9. 3.9 跨分頁搬移、複製積木
10. 3.10 雙擊副程式呼叫積木，跳到定義的位置
