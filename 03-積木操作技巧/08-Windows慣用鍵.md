# 3.8 Windows 慣用鍵

除了複製貼上（[3.5](05-複製貼上.md)）、復原重做（[3.7](07-上一步下一步.md)），軟體也補上了幾個大家在 Windows 上已經很習慣的快捷鍵，作用在目前選取的積木上：

| 按鍵 | 效果 |
|---|---|
| `Ctrl+A` | 全選畫布上目前分頁的所有積木 |
| `Ctrl+X` | 剪下選取的積木（複製＋從畫布上移除） |
| `Delete` 或 `Backspace` | 刪除選取的積木 |

## 為什麼特別提這幾個

Blockly 本身沒有內建這幾個按鍵的行為——不特別處理的話，在編輯器裡按 `Ctrl+A` 會變成瀏覽器原生的「選取畫面上所有文字」（積木文字、程式碼預覽區整片反白，很干擾），而不是選取積木。這幾個按鍵是額外接上去的，讓整個操作習慣更符合一般人用慣的 Windows 軟體。

這三個按鍵都是作用在 [3.3 選取積木](03-選取積木.md) 介紹的**選取集合**上，跟 `Ctrl+C`／`Ctrl+V`、跨分頁搬移、加入收藏是同一套選取機制，行為是一致的。
