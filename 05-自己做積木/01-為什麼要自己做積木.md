# 5.1 為什麼要自己做積木

軟體內建的積木涵蓋了 Arduino 常見的操作（腳位、感測器讀值、通訊協定⋯），但市面上的模組千百種，不可能每一種都內建一顆對應積木。當你買到一個新模組、廠商給了一段 C++ 範例程式碼，卻找不到對應的積木可以用時，就是「自己做積木」派上用場的時候。

## 適合自己做積木的情況

- 買了一個新感測器／模組，廠商提供 Arduino 函式庫跟範例程式碼，但軟體沒有內建對應積木。
- 想把一段自己常用、有點長的程式碼包成一顆積木，之後用拖的就好，不用每次複製貼上文字積木。
- 想固定住某些參數的組合（例如某個腳位固定接某個感測器），做成一顆「一鍵搞定」的專用積木。

## 不用自己寫程式碼

整個過程是**六步精靈**（見 [5.2](02-六步做出一顆積木.md)），用選單、輸入框一步步填表單完成：這顆積木長什麼樣子、有哪些可以填的參數、放開之後要產生哪一行 C++ 程式碼。就算完全不熟 C++，只要照著模組廠商給的範例程式碼填進對應的欄位，也能做出堪用的積木。當然，如果本來就會一點 C++，可以做得更精緻（例如同時用到好幾行程式碼、包含 `#include` 函式庫）。

## 跟「純文字 C 程式碼」積木有什麼不同

[C 語言類](../04-積木字典/12-C語言.md)的「純文字 C 程式碼」積木也能讓你直接寫程式碼，但那是**一次性**的、埋在畫布上的一段文字。自己做的積木則是**可以重複使用、可以帶參數**的一顆正式積木，做好之後跟內建積木一樣可以在積木箱裡找到、可以拖出來用很多次，甚至可以[收藏](../03-積木操作技巧/04-積木收藏區.md)、可以[匯出給別的老師](04-積木包管理匯出與匯入.md)。
