# 4.4 輸入類

從板子腳位「讀」東西回來：按鈕有沒有按、感測器讀到多少數值，都在這裡。

![輸入類積木箱](../images/04-dictionary/flyout-輸入.png)

| 積木 | 說明 |
|---|---|
| 腳位 ＿ 的狀態是高電位 | 讀取數位腳位目前是高電位還是低電位。接按鈕的話，選「內建上拉電阻」不用外接電阻，但**按下時讀到的其實是低電位**，要接「不是」積木（[運算類](02-運算.md)）才會變成「按下＝成立」。 |
| 類比腳位 ＿ 的數值 | 讀取類比腳位的數值，範圍是 0～1023。可以接可變電阻、光敏電阻這類感測器。**A6、A7 只有 Nano 板子才有，Uno 沒有這兩支腳**。 |
| 腳位 ＿ 上升／下降／改變 時執行副程式 ＿ | 設定一個中斷：腳位電位變化的當下，會立刻暫停正在做的事，跑一次選好的副程式，做完再繼續。**只有腳位 2、3 支援**（Uno/Nano 硬體限制）。副程式要是「沒有參數、沒有回傳值」的才能選。 |
| 取消腳位 ＿ 的中斷設定 | 取消之前用「腳位…時執行副程式」設定的中斷，之後腳位電位變化就不會再自動跑副程式了。 |
| 腳位 ＿ 維持 高／低電位 的時間（微秒），最多等 ＿ 微秒 | 量測腳位維持在指定電位的時間長度（微秒＝百萬分之一秒），等超過最多等待時間還沒開始就回傳 0。**超音波測距感測器（例如 HC-SR04）最常用**這個積木讀回音時間，再自己換算成距離。 |

## 小提醒

- 按鈕最常見的接法：腳位設為「輸入（內建上拉電阻）」，讀到「低電位」代表按下——記得接一顆「不是」積木，這樣「成立＝按下」比較符合直覺。
- 中斷（腳位…時執行副程式）是進階用法，適合「要立刻反應、不能等主迴圈跑到」的情境，例如緊急停止按鈕。一般判斷按鈕用「如果」＋「腳位狀態」就夠了。
