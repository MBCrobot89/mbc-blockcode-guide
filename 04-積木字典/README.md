# 四、積木字典

> 🚧 這一章內容製作中，會陸續補上每一類積木的詳細用法與範例。

依照左邊積木分類欄的順序，每個分類會有一頁，說明該分類每一顆積木的用途、參數意義，並附上範例。

## 規劃中的章節（對應 12 個積木分類）

1. 4.1 控制類（重複 N 次、迴圈次數、if/switch、等待、跳出迴圈）
2. 4.2 運算類（四則運算、比較、邏輯、位元運算、限制範圍、對應區間、亂數）
3. 4.3 輸出類（數位輸出、類比輸出 PWM、伺服馬達、蜂鳴器）
4. 4.4 輸入類（數位讀取、類比讀取、中斷、脈衝偵測）
5. 4.5 通訊類（序列埠、I2C、SPI）
6. 4.6 除錯類（內建 LED 測試）
7. 4.7 變數類（宣告、讀取、設定、增加）
8. 4.8 陣列類（宣告、取值、設值、長度）
9. 4.9 文字類（文字變數、串接、長度、轉數字）
10. 4.10 儲存類（EEPROM 讀寫）
11. 4.11 副程式（有／無返回值、參數、返回積木）
12. 4.12 C 語言類（插入原生 C 程式碼）
