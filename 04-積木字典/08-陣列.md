# 4.8 陣列類

陣列是「一整排」的變數，像一排有編號的箱子，一次可以記住好幾個數值。

![陣列類積木箱](../images/04-dictionary/flyout-陣列.png)

| 積木 | 說明 |
|---|---|
| 宣告 ＿ 陣列 ＿ 大小 ＿ | 建立一個陣列，用來儲存多個相同類型的數值。 |
| 陣列 ＿ 的第 ＿ 項（從 0 開始） | 讀取陣列中指定位置的數值。下拉選單只會列出站在這個位置看得到的陣列。 |
| 把陣列 ＿ 的第 ＿ 項（從 0 開始）設為 ＿ | 改變陣列中指定位置的數值。下拉選單只會列出站在這個位置看得到的陣列。 |
| 陣列 ＿ 的長度 | 取得這個陣列的大小。下拉選單只會列出站在這個位置看得到的陣列。 |
| 宣告 ＿ 副程式專用的陣列 ＿ 大小 ＿ 記住上次的值 ＿ | 只有這個[副程式](11-副程式.md)裡面看得到這個陣列，別的副程式不會互相影響，即使名字取得一樣也不會混在一起。勾選「記住上次的值」的話，下次呼叫這個副程式時，陣列裡的內容會是上次執行完的樣子；沒勾選的話，每次呼叫都會是全新、空的陣列。**要放在副程式的積木堆疊裡面**（不要放在 if／重複 裡面），這樣副程式裡其他地方才都能用它。 |

## 「從 0 開始」是什麼意思

陣列的第一項編號是 **0**，不是 1——如果陣列大小是 5，可以用的編號是 0、1、2、3、4，總共 5 個位置。這是所有程式語言的通用習慣，跟一般數數字「第一、第二…」不一樣，第一次用容易搞混，多練習幾次就會習慣。

常見用法：搭配[控制類](01-控制.md)的「重複 ＿ 次」加上「迴圈次數 i」，可以一次跑過陣列裡所有的項目（i 從 0 開始剛好對應陣列編號）。
