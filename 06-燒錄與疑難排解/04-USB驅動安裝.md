# 6.4 USB 驅動安裝（五種晶片完整說明）

操作步驟（自動偵測、手動選單）已經在 [1.4 板子插上沒反應？先裝 USB 驅動程式](../01-快速開始/04-安裝USB驅動程式.md) 講過，這裡補完五種晶片各自的細節，遇到自動偵測沒抓到、想自己判斷該裝哪一種時查。

## 軟體認得的五種晶片

| 晶片 | 常見於 | 驅動程式 |
|---|---|---|
| CH340／CH341 | 便宜的 Uno／Nano 相容板，**最常見** | 內建 `CH341SER.EXE` 安裝檔 |
| CH343／CH9102 | 較新款的相容板 | 內建 `CH343SER.EXE` 安裝檔（跟 CH340/341 廠商相同，用晶片內部編號分辨是哪一種） |
| CP2102／CP210x | 部分相容板、少數模組板 | 內建 Silicon Labs 官方安裝檔 |
| FTDI（FT232 等） | 較舊、較高階的板子 | 不用另外裝安裝檔，透過 Windows 內建的驅動安裝機制（`.inf` 檔）直接裝 |
| Prolific PL2303 | 少數舊板子 | **軟體沒有內建**，選這項會導向官方網站下載 |

## 這些板子插上不用裝任何驅動

如果板子上的晶片是以下幾種，Windows 通常**內建就認得**，插上直接能用，不用跑安裝流程：

- 原廠 Arduino（官方 Uno／Nano，晶片上直接整合 USB 功能）
- ESP32 原生開發板
- Adafruit 出的板子
- SparkFun 出的板子

> 💡 這套軟體目前燒錄只支援 ATmega328P（Uno／Nano），上面列的 ESP32 等屬於[未來硬體規劃](07-目前只支援ATmega328P.md)，這裡只是說明「免驅動」這件事本身，不代表現在就能燒錄成功。

## 怎麼判斷板子是哪一種晶片

板子上除了那顆主要的 ATmega328P（通常印著這個字樣、面積比較大），旁邊另一顆比較小的方形晶片就是負責 USB 通訊的晶片，上面印的型號字樣（例如「CH340」「CP2102」）就對得上表格裡的分類。看不清楚的話，也可以直接用[說明選單的自動偵測功能](../01-快速開始/04-安裝USB驅動程式.md)，軟體會自己判斷。

## 手動裝完還是沒反應？

1. 確認是插著板子的狀態下裝驅動（先插上板子，Windows 才看得到「有一個裝置在等驅動」）。
2. 裝完驅動後，**把板子拔掉、重新插上**，讓 Windows 重新辨識一次。
3. 回到軟體，按連接埠下拉選單旁邊的 🔄 重新整理。
4. 還是不行，換一條傳輸線、換一個 USB 孔再試一次（參考 [6.2](02-找不到板子的三步驟排查.md)）。
