# 6.7 目前只支援 ATmega328P（Uno／Nano）

MBC 圖控編程目前**只能編譯、燒錄 ATmega328P 晶片的開發板**，也就是：

- **Arduino Uno**（含官方版與相容版）
- **Arduino Nano**（含常見的 CH340 版相容板）

## 為什麼不支援其他板子？

市面上還有 ESP32、STM32 等其他晶片的開發板，需要完全不同的編譯器與燒錄流程。要讓軟體同時支援多種晶片、或是開放讓使用者自己擴充編譯器，技術上做得到，但會讓安裝檔變得很肥大、維護也更複雜。目前先把 Uno／Nano 這條最常見的路做穩，其他硬體支援列在未來規劃中。

## 怎麼確認我的板子是不是 Uno / Nano

- 看板子上印的字，通常直接寫著「UNO」或「NANO」。
- 相容板（非官方原廠）也可以用，只要晶片是 ATmega328P（板子上另一顆比較大的晶片，旁邊常印著 `ATMEGA328P` 字樣）。
- 如果板子上印著「ESP32」「ESP8266」「STM32」，**目前這套軟體還沒辦法幫它燒錄**。
