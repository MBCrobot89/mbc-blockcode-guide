# 1.1 安裝軟體

## 安裝步驟

1. 雙擊拿到的安裝檔（檔名類似 `MBC BlockCode-安裝檔-1.0.0.exe`）。
2. Windows 可能會跳出「這個應用程式可能會對你的裝置造成損害」的提示，點選**仍要執行**（這是因為安裝檔沒有付費的數位簽章，不代表軟體有問題）。
3. 安裝精靈會問你要裝在哪個資料夾，**建議直接用預設的位置**（`C:\MBC_BlockCode`），不需要更改。
4. 一路按**下一步**到安裝完成。

<div class="step-note">

💡 **為什麼預設裝在 `C:\` 底下，不是「本機磁碟(C:) → Program Files」？**
因為之後你要自己匯入 Arduino 函式庫（詳見 [自己做積木](../05-自己做積木/README.md)），這些檔案要放在軟體安裝的資料夾裡。Windows 對 `Program Files` 資料夾有寫入限制，一般帳號常常放不進去；裝在 `C:\` 底下就沒有這個問題。

</div>

## 安裝完成後

桌面與開始選單會出現這個圖示：

![MBC 圖控編程的桌面圖示](../images/favicon.png ':size=96')

雙擊它就可以打開軟體了。

## 如果之前裝過舊版本

直接安裝新版即可，安裝程式會自動覆蓋更新，**你自己匯入的函式庫、右上角的網站連結設定都會保留**，不會被清空。
