# 1.4 板子插上沒反應？先裝 USB 驅動程式

第一次用某片板子時，如果連接埠下拉選單裡完全沒有出現任何選項、或是按了「編譯並燒錄」說找不到板子，**很可能是這台電腦還沒有裝這片板子需要的 USB 驅動程式**。

## 什麼是 USB 驅動程式？為什麼需要它？

板子上有一顆負責「USB 轉序列埠」的小晶片，電腦要先認得這顆晶片、幫它變成一個「連接埠（COM 埠）」，軟體才找得到它。這個「讓 Windows 認得晶片」的動作就是安裝驅動程式——**驅動程式沒裝好的話，電腦連這是一個裝置都不知道，更不用說燒錄程式了**。

## 讓軟體自動幫你找出該裝哪一種

MBC 圖控編程認得市面上最常見的五種晶片，而且**內建了驅動程式安裝檔**，不用自己上網找：

1. 點上方選單的「**說明**」→「**安裝 USB 驅動程式**」→「**自動偵測我的板子需要哪一種…**」。
2. 軟體會檢查電腦上有沒有「插著、但還沒裝驅動」的裝置，如果找到會直接告訴你是哪一種晶片，並且問你要不要現在安裝。
3. 按**安裝驅動程式**，跟著跳出來的安裝精靈一路按下一步即可。
4. 裝完之後**把板子拔掉重新插上**，回到軟體按連接埠下拉選單旁邊的 🔄 重新整理，應該就找得到了。

## 如果自動偵測沒找到

也可以自己從選單手動挑一個晶片安裝，「說明」→「安裝 USB 驅動程式」選單裡列出所有支援的晶片，選單項目長這樣：

```
說明
 └─ 安裝 USB 驅動程式
     ├─ 自動偵測我的板子需要哪一種…
     ├─ ────────────
     ├─ CH340／CH341        （最常見，便宜的相容板大多是這顆）
     ├─ CH343／CH9102       （較新的板子）
     ├─ CP2102／CP210x
     ├─ FTDI（FT232 等）
     └─ Prolific PL2303     （需連網下載）
```

怎麼知道該選哪一個？板子上那顆比較大、印著字的方形晶片，上面印的型號通常就對得上其中一項（例如晶片上印著「CH340」字樣）。
