# 7.4 匯出 .ino 給 Arduino IDE 用

`.abp` 是這套軟體自己的格式，如果想把積木產生出來的程式碼**帶去官方 Arduino IDE**（或給比較懂程式的人用純文字編輯），可以用「檔案」選單裡的「匯出 .ino...」。

## 怎麼用

上方選單「檔案」→「匯出 .ino...」，選好存檔位置跟檔名，軟體會把目前分頁積木產生出來的完整 C++ 程式碼存成一個 `.ino` 檔案。

## 幾個跟一般存檔不一樣的地方

- **自動包一層同名資料夾**：Arduino IDE 規定 `.ino` 檔案要放在「跟檔名一模一樣的資料夾」裡（例如 `my_robot/my_robot.ino`），不然 Arduino IDE 打開時會強迫你另存一份。軟體會自動幫你包好這層資料夾，不用自己手動建立、搬動檔案。
- **檔名自動加上時間戳記**：不管你在存檔對話框裡打了什麼檔名，存出來的檔案都會自動加上匯出當下的時間，同一份程式多次匯出也不會互相覆蓋掉。
- **檔名、路徑請用英文**：Arduino IDE 底層的編譯工具鏈對中文路徑或檔名的處理不太可靠，資料夾、檔名裡有中文字的話，之後在 Arduino IDE 可能會打不開或編譯失敗。建議匯出到英文路徑、用英文檔名。

## 什麼時候會用到

- 想在 Arduino IDE 裡對照著看、或用進階功能（例如函式庫管理員）繼續開發。
- 給比較懂程式的學生／同事看實際的 C++ 程式碼長什麼樣。
- 這套軟體只支援 ATmega328P（Uno／Nano），如果想把同樣的邏輯移植到其他板子，匯出 `.ino` 之後可以用 Arduino IDE 針對其他硬體重新編譯。

> 💡 一般教學情境下不太需要用到這個功能，[程式碼預覽](../02-軟體介面導覽/04-程式碼預覽.md)本身就能直接看到、複製產生出來的程式碼。
