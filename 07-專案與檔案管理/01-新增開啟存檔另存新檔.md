# 7.1 新增、開啟、存檔、另存新檔

工具列右下角這六顆圖示，前四顆就是最基本的檔案操作（見 [2.3 右上角工具列](../02-軟體介面導覽/03-工具列.md)）：

| 圖示 | 動作 | 快捷鍵 |
|---|---|---|
| 🆕 新增 | 開一份新的空白程式，變成一個新分頁，不會動到其他已經開著的分頁 | `Ctrl+N` |
| 📂 開啟 | 開啟一個已經存在的程式檔案，加開一個新分頁 | `Ctrl+O` |
| 💾 存檔 | 把目前分頁的內容存回原本的檔案；第一次存檔（還沒有檔名）會跳出存檔對話框 | `Ctrl+S` |
| 📤 另存新檔 | 存成一份新的檔案（保留原檔不動），存完之後目前分頁改為指向新檔案 | `Ctrl+Shift+S` |

這幾個動作在上方選單「檔案」裡也找得到，快捷鍵一樣。

## 存檔格式

程式存成 **`.abp`** 檔案，內容是純文字的 JSON 格式，記錄了：

- 畫布上所有積木的內容跟排列
- 這份作品用到的[自製積木](../05-自己做積木/README.md)定義（如果有用到的話）
- 建立時間、上次修改時間

`.abp` 只認這套軟體自己（用文字編輯器打開會看到一堆看不懂的 JSON，不用去改它），雙擊 `.abp` 檔案不會自動用這套軟體開啟，要先開啟軟體，再用「開啟」選這個檔案。

## 小提醒

- 每個分頁是**各自獨立的檔案**，不是同一個檔案裡的好幾個分頁——詳見 [7.5 一個檔案＝一個分頁](05-一個檔案等於一個分頁.md)。
- 存檔前如果這個分頁有未存檔的變更，分頁標籤名稱前面會有一個黑點提醒（見 [2.7 分頁列](../02-軟體介面導覽/07-分頁列.md)）。
- 就算忘記手動存檔，[自動存檔](02-自動存檔.md)每 30 秒會幫你存一次，不用太擔心忘記存檔遺失內容。
