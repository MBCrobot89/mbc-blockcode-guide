# MBC 圖控編程 使用手冊

歡迎使用 **MBC 圖控編程**（英文名稱 MBC BlockCode）——用「拖積木」的方式寫 Arduino 程式的軟體，設計給完全沒學過程式的老師和學生使用。

這本手冊會帶你從安裝軟體開始，一路教到自己做一顆新積木。左邊選單可以直接點想看的章節，也可以用上方（或側邊選單最上面）的搜尋欄輸入關鍵字。

## 從這裡開始

如果是第一次用這套軟體，建議照順序看：

1. **[快速開始](01-快速開始/01-安裝軟體.md)** —— 安裝軟體、第一次打開、拖出你的第一個程式
2. **[軟體介面導覽](02-軟體介面導覽/00-總覽.md)** —— 畫面上每一個按鈕、每一個區塊是做什麼的
3. **[積木操作技巧](03-積木操作技巧/README.md)** —— 拖、選、複製、刪除，這些技巧每一種積木都用得到
4. **[積木字典](04-積木字典/README.md)** —— 查每一顆積木實際的用法

已經會用了，想查特定功能：

- 想**自己做一顆新積木**（例如接超音波感測器）→ [自己做積木](05-自己做積木/README.md)
- 板子插上去**沒反應、燒不進去** → [燒錄與疑難排解](06-燒錄與疑難排解/README.md)
- 想知道存檔在哪裡、怎麼管理好幾個程式 → [專案與檔案管理](07-專案與檔案管理/README.md)
- 想在軟體上加自己學校的網站連結 → [老師專屬設定](08-老師專屬設定/README.md)

## 這套軟體目前支援的板子

> ⚠️ **目前只支援 ATmega328P 晶片的開發板**（Arduino **Uno**、**Nano** 及相容板，例如常見的 CH340 版 Nano）。ESP32、STM32 等其他晶片的開發板**還不能用這套軟體燒錄**，未來規劃會支援，但現在請先確認手上的板子是 Uno 或 Nano。
